# 03 · 排版与交付（MagazineCaptionStudio）

## 这是什么

一个**本地小工具**：上传一张出好的图 → 叠上杂志文字 / 装饰 / 色块 → 下载成品。

- 跑在**你自己电脑上**，不上传云端，不用联网
- 网页调参，**改一下右侧预览立刻跟着变**
- 满意后点「生成」出成品 PNG

## 启动与关闭

解压 `MagazineCaptionStudio.zip`，然后：

| 操作 | 做什么 |
|---|---|
| 双击 **`启动.bat`** | 自动找 Python → 后台起服务 → 打开浏览器页面 |
| 双击 **`停止.bat`** | 停服务 + 清掉临时文件 |

> 启动后**别关那个黑窗口**（它其实是隐藏的）；用完记得双击 `停止.bat` 清理。

## 网页怎么用

1. **上传图** —— 点上传区或把图拖进去
2. **选预设** —— 左侧「7 · 预设」里选，默认就是 **Magazine Poster 01**
3. **调参** —— 左侧各分组；右侧预览实时跟着变
4. **点「生成」** —— 出成品（预览只是预览，成品要点生成）
5. **下载** —— 「下载当前 PNG」或「下载整批 ZIP」

**几个要点**：

- **改参数不会自动出图** —— 右侧实时预览会立刻变，但成品必须点「生成」
- **随机种子**：框里显示的是当前种子。**同一个种子 = 同一版版面**；改参数**不会**换种子（所以预览是稳的）。想换版面点「换一批」
- **「自动换种子」勾选框**：勾上后每点一次「生成」都换新种子（抽卡用）

## 三个预设

| 预设 | 什么样 |
|---|---|
| **Magazine Poster 01**（默认） | 斜色带 + 顶部品牌 + 底部信息行 + 右下色块 + 装饰散布。**配套上面那套出图风格** |
| **Cover 01** | 封面风：满版照片 + 大字压在人物身上，刊头被人物压住（分层） |
| **极简线条** | 示例预设，线条 + 留白 |

## 标题从哪来（重要）

工具会按这个顺序找标题：

```
① 你在网页上手动填的
② 图片自带的元数据（键名 MagazinePoster）
③ 从图片内嵌的提示词里解析
④ 预设的默认值
```

**如果你出图时没有写元数据**，第 ② 步会跳过，走第 ③ 步 —— 那它只能**猜**，猜错是常事。

**所以推荐**：出图后，在网页上**手动填**标题和角色名（「2 · 文字」组里），最省心。

> 元数据是什么：PNG 里的一小块隐藏文本，存 `{标题, 角色名, 作品名}`。原作者的出图脚本会自动写；你的没有，就手填。

## 命令行用法（可选）

适合批量或脚本调用。需要 Python 3 + Pillow。

```bash
python caption.py 图片.png                    # 出一张，默认预设
python caption.py 图片.png --preset cover-01  # 换预设
python caption.py 图片.png --seed 42          # 固定种子，结果可复现
python caption.py 图片.png --title ANON       # 直接指定标题
python caption.py 图片.png --cutout           # 开启抠图分层（人物压住文字）
```

## 依赖与环境

| 需要 | 说明 |
|---|---|
| **Python 3 + Pillow** | 引擎依赖。**只用 Pillow**，不需要 numpy 或其他库 |
| **Microsoft Edge** | 用来把网页渲染成 PNG。Windows 一般自带；没有的话装一个 Chrome 也行 |

`启动.bat` 会自动找 Python；如果找不到，会问你要不要装 Pillow。

## 常见问题

| 现象 | 原因 / 解法 |
|---|---|
| 双击 `启动.bat` 没反应 | 可能缺 Python。看窗口提示，按提示装 |
| 网页打不开 | 服务没起来。重新双击 `启动.bat`，等几秒再刷新 |
| 生成很慢（20 秒+） | 引擎要启动一次无头浏览器渲染。**机器上 Edge 进程多的时候会慢**，属正常 |
| 标题是空的 / 猜错了 | 见上面「标题从哪来」—— **手动填最省心** |
| 生成的图被压扁 / 只显示一半 | 预设文件被改坏了。用原包里的 `presets/` 覆盖回去 |
| 关闭服务后图都没了 | 临时文件会清掉，**已下载的成品不受影响** |

## 预设怎么加

预设就是一个 JSON 文件，放在 `presets/` 里，**加一个文件就多一个选项**（加完刷新网页）。

格式见 `使用说明.txt`（包里有），或参考现成的 `presets/magazine-poster-01.json`。
